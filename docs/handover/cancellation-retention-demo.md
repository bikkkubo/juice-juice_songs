# 目的

- Adobeの解約体験をケーススタディとして、サブスクリプション解約時のリテンション施策について「採用可能なUI」と「避けるべきUI」を社内で共通認識にする。
- 法務・PM・デザイン・開発が同じ画面を見ながら、解約妨害ではなく選択支援型のリテンションを検討できる、単一HTMLのインタラクティブ資料を提供する。

# 決定事項

- 意図的に解約を面倒にする施策は推奨例として扱わず、規制・訴訟・信頼毀損リスクを説明するNG教材として扱う。
- 推奨設計は「解約導線を隠さない」「理由回答は任意」「理由に応じた提案は1回」「拒否後は最短で解約完了」を基本とする。
- 契約画面では、月額だけでなく契約期間、年間総額、早期解約料の計算式と具体例を同じ視認領域に表示する。
- 解約画面では、終了日、最終請求額、算定根拠、失う機能、保存データの状態を確定前に表示する。
- xChartの既存方針に合わせ、保存データはアカウントが存在する限り保持され、同じアカウントで再契約した際に利用できる例示とした。
- Adobeの行為については断定表現を避け、米司法省・FTCの訴状における政府側の主張と、2026年3月公表の和解案を区別して記載する。
- 実物のAdobeスクリーンショットは使用せず、コードで作成した模式図を使用する。

# 注意点

- このHTMLは社内検討用プロトタイプであり、法的助言または本番仕様ではない。
- AdobeのUIは実物の複製ではなく、政府資料に記載された特徴の模式的な再構成である。
- 早期解約料や無料体験の扱いは国・地域・契約形態・決済手段で要件が異なるため、本番適用前に個別の法務確認が必要。
- FTCのClick-to-Cancel規則は2025年7月に手続上の理由で無効化されたが、欺瞞的な表示・解約妨害に対する既存法や州法まで無効になったわけではない。
- 「解約不能率」を成功KPIにせず、休止転換率、ダウングレード率、復帰率、問い合わせ率、苦情、チャージバックも併せて評価する。
- このworktreeは元リポジトリの別作業から分離されている。引き継ぎ後も無関係なルートworktreeの変更を取り込まないこと。
